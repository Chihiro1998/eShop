## Project goal

We will build an **e-commerce site** that allows users to browse, search, and purchase products online. Our platform will feature a user-friendly interface, secure authentication, and an efficient order management system. The goal is to provide a seamless shopping experience for customers while enabling administrators to manage inventory and sales effectively.

## User stories

### Customer
- As a customer, I want to browse and search for products so that I can find what I want to buy.
- As a customer, I want to add products to a shopping cart so that I can review and purchase them later.
- As a customer, I want to securely check out and make payments so that I can complete my purchase.
- As a customer, I want to track my orders so that I know when to expect delivery.

### Admin
- As an admin, I want to add, update, and remove products so that I can manage the inventory.
- As an admin, I want to view and process orders so that I can fulfill customer purchases.
- As an admin, I want to manage user accounts so that I can ensure system security.

## UI design

Our UI design will be created using **Figma** and will include:

- **Homepage:** Featuring product categories, search bar, and featured items.
- **Product Page:** Detailed information, images, reviews, and "Add to Cart" button.
- **Cart Page:** List of selected products with the option to update quantities or remove items.
- **Checkout Page:** Secure payment gateway integration.
- **Admin Dashboard:** Inventory management, order tracking, and user management.

## Project requirements

### Back End
- **Technology Stack:** Node.js with Express.js for server-side logic.
- **Database:** MongoDB for product, user, and order data.
- **Authentication:** JWT-based authentication for users and admins.

### Web API
- **RESTful API:** Expose endpoints for product management, user authentication, and order processing.
- **Third-party Integration:** Payment gateway (e.g., Stripe or PayPal) for secure transactions.

### Data
- **User Data:** Authentication, order history, and preferences.
- **Product Data:** Name, price, description, stock availability, and images.
- **Order Data:** User orders, status tracking, and payment information.

### User/Admin Views
- **Customer Views:** Homepage, product pages, cart, checkout, and order history.
- **Admin Views:** Dashboard with product and order management capabilities.
